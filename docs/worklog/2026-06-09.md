## 공통 로그아웃 추가

### 작업 목적
- 권한별 로그아웃 URL이 잘못된 헤더에서 호출될 경우 403이 발생하는 문제를 해결한다.
- `ADMIN`, `MANAGER`, `MEMBER` 권한과 관계없이 공통 `/logout`으로 세션을 종료할 수 있게 한다.

### 수정한 파일
- `src/main/java/com/ssg/wms/common/CommonController.java`
- `src/main/java/com/ssg/wms/config/RoleCheckInterceptor.java`
- `src/main/webapp/WEB-INF/views/admin/admin-header.jsp`
- `src/main/webapp/WEB-INF/views/warehousemanager/manager-header.jsp`
- `src/main/webapp/WEB-INF/views/member/member-header.jsp`
- `src/test/java/com/ssg/wms/config/RoleCheckInterceptorTest.java`

### 수정 전 코드
```jsp
<a class="dropdown-item" href="${pageContext.request.contextPath}/admin/logout">
```

```jsp
<a class="dropdown-item" href="${pageContext.request.contextPath}/warehousemanager/logout">
```

```jsp

```

### 수정 후 코드
```java
@GetMapping("/logout")
public String logout(HttpServletRequest request) {
    HttpSession session = request.getSession(false);

    if (session != null) {
        session.invalidate();
    }

    return "redirect:/login";
}
```

### 수정 이유
- 로그아웃은 특정 업무 권한이 아니라 인증 세션 종료 기능이다.
- 기존 권한별 로그아웃 URL은 잘못된 헤더가 노출된 상황에서 인터셉터 권한 검사에 막혀 세션 종료까지 도달하지 못했다.
- 공통 `/logout`을 공개 경로로 허용해 세션이 있으면 무효화하고, 세션이 없어도 로그인 화면으로 이동하도록 처리했다.

### 추가로 해야 할 작업
- 기존 권한별 로그아웃 메서드는 호환성을 위해 유지했다. 추후 사용처가 완전히 사라지면 제거를 검토한다.
