## 수정 이유
- `SalesVO`, `ExpenseVO`가 접두어가 붙은 필드명으로 변경되었는데 테스트 코드가 이전 API를 계속 사용하고 있어 `compileTestJava`에서 `cannot find symbol`이 발생했다.
- 테스트 이름과 문자열 일부가 깨져 있어 UTF-8 기준의 정상 한글로 복구했다.

## 추가로 해야 할 작업
- Smart Tomcat 실행 전에 IntelliJ의 Gradle JVM을 `JDK 8` 또는 최소 프로젝트와 호환되는 버전으로 맞추면 `source value 8 is obsolete` 경고를 줄일 수 있다.
