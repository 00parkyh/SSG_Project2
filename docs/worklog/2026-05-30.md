- `gradle/wrapper/gradle-wrapper.jar`

## 수정 전 코드

```gitignore
*.jar
# *.war
```

`gradle/wrapper/gradle-wrapper.jar` 파일이 없어 `.\gradlew test` 실행 시 `org.gradle.wrapper.GradleWrapperMain` 클래스를 찾지 못했다.

## 수정 후 코드

```gitignore
*.jar
!gradle/wrapper/gradle-wrapper.jar
# *.war
```

로컬 Gradle 8.10 캐시의 `gradle.bat`을 사용해 다음 명령으로 Wrapper를 재생성했다.

```powershell
gradle wrapper --gradle-version 8.10
```

## 수정 이유

- Gradle Wrapper는 `gradle/wrapper/gradle-wrapper.jar`가 있어야 독립적으로 실행된다.
- `.gitignore`의 `*.jar` 규칙 때문에 복구된 Wrapper JAR가 Git에 포함되지 않는 문제가 있어, 해당 파일만 예외 처리했다.
