
```jsp

    <jsp:include page="/WEB-INF/views/member/member-header.jsp" />
</c:when>
```

## 수정 이유

- 회원이 `창고 목록 조회`, `창고 위치 조회`, `창고 상세` 화면으로 들어가면 공용 창고 JSP가 관리자 헤더/푸터를 사용해 회원 메뉴가 사라지는 문제가 있었다.
- 회원 헤더의 창고 메뉴는 활성화 조건이 없어 현재 위치 표시가 동작하지 않았다.
- 세션 역할이 `MEMBER` 인 경우 회원 헤더/푸터를 사용하고, `pageActive` 기준으로 창고 메뉴를 열어 주면 역할별 UI가 일관되게 유지된다.

## 수정 후 코드


```jsp
<c:set var="pageActive" value="announcements" scope="request"/>
<c:choose>
    <c:when test="${sessionScope.role eq 'ADMIN'}">
        <jsp:include page="/WEB-INF/views/admin/admin-header.jsp" />
    </c:when>
    <c:when test="${sessionScope.role eq 'MANAGER'}">
        <jsp:include page="/WEB-INF/views/warehousemanager/manager-header.jsp" />
    </c:when>
    <c:otherwise>
        <jsp:include page="/WEB-INF/views/member/member-header.jsp" />
    </c:otherwise>
</c:choose>
```

## 수정 이유

- 메뉴 클릭 후 상세, 등록, 수정 화면으로 이동했을 때도 같은 상위 메뉴가 열려 있어야 현재 위치를 바로 파악할 수 있음
- 회원/창고관리자도 공지사항, 문의사항 같은 공용 화면에서 자기 역할 헤더를 유지해야 메뉴가 관리자용으로 바뀌지 않음
- 관리자 입고 메뉴는 하위 항목만 활성화되고 상위 메뉴가 접히는 상태라 가독성이 떨어져 상위 `active open` 처리까지 맞춤
