## 수정 후 코드

```jsp
messageElement.textContent = alertMessage;
overlay.hidden = false;
renderTimerText();
confirmButton.focus();

confirmButton.addEventListener("click", proceed);
overlay.addEventListener("keydown", function (event) {
    if (event.key !== "Enter") {
        return;
    }

    event.preventDefault();
    proceed();
});
```

## 수정 이유

- 기존 구현은 마우스로 `확인` 버튼을 눌렀을 때만 안내 모달이 닫히거나 리다이렉트되어 키보드 사용 흐름이 끊김
- 모달 표시 시 확인 버튼에 포커스를 주고 `Enter` 키를 `proceed()` 에 연결하면 버튼 클릭과 동일한 UX를 제공할 수 있음

## 수정 후 코드

```xml
<select id="sectionDropDown" resultType="com.ssg.wms.product_stock.dto.DropdownDTO">
    SELECT s.section_id AS id,
           CONCAT(w.warehouse_name, ' - ', s.section_name) AS name
    FROM Section s
    JOIN Warehouse w ON w.warehouse_id = s.warehouse_id
    ORDER BY w.warehouse_name, s.section_name
</select>
```

## 수정 이유

- 기존 쿼리는 `section_name` 만 표시해서 서로 다른 창고에 같은 섹션명이 있으면 드롭다운에서 중복으로 보였음
- `sectionId` 값은 유지하면서 표시명에 창고명을 함께 붙이면 중복처럼 보이는 문제를 없애고 선택 대상도 명확해짐

```javascript
function loadSectionsByWarehouse(warehouseId) {
    if (!warehouseId) {
        resetSectionOptions('창고를 먼저 선택해주세요');
        return Promise.resolve();
    }

    return fetch('/stock/sections?warehouseId=' + encodeURIComponent(warehouseId))
        .then(function (response) {
            return response.json();
        })
        .then(function (sectionList) {
            populateSectionOptions(sectionList);
        });
}
```

## 수정 이유

- 섹션은 전체 목록을 한 번에 보여주는 것이 아니라 선택한 창고에 속한 섹션만 보여줘야 검색 조건으로 의미가 있음
- 창고 변경 시 섹션을 다시 조회하도록 해야 같은 이름의 섹션이 섞여 보이지 않고 잘못된 조합 선택도 막을 수 있음
- 재고 조회, 재고 실사, 품목 현황 모두 동일한 창고-섹션 의존 관계를 가지므로 같은 방식으로 맞춤

- 재고 실사와 품목 현황 화면에서도 동일하게 창고 선택 후 섹션 목록이 갱신되는지 확인
